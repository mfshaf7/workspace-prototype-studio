# Graduation Checklist

Use this checklist before a prototype leaves Workspace Prototype Studio.

- Target home is explicit: Workspace Delivery ART, existing repo, new repo,
  client portfolio, or retirement.
- Owner repo and runtime owner are named.
- Security triggers have been reviewed or waived by the right authority.
- Data mode and mutation boundary are safe for the target home.
- Design baseline is approved or explicitly superseded.
- Prototype source to be retained is identified.
- Prototype source to be deleted is identified.
- New repo intake classification is complete when the target is a new repo.
- Devint, stage, and prod expectations are not mixed.
- Graduation record is created under `records/graduations/`.
