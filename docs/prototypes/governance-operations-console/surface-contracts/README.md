# Cross-Surface Contracts

Status: cross-surface contract index.

These contracts cover console surfaces that are not owned by one Operation
Workbench domain. They must not absorb domain record editing or become shadow
workbenches.

## Surface List

- `command-center-focus.md` - cross-console actionable-attention projection,
  deterministic ranking, source admission, navigation, and adaptive layout
  contract
- `identity-and-authorization.md` - Operator Account, profile preferences,
  identity trust projection, access/session command posture, and future
  enforcement boundary
- `lifecycle-transitions.md` - shared lifecycle-transition authority, route,
  artifact, and projection contract
- `environment-lifecycle.md` - dev-integration profile operations and
  product-capability-gated release and runtime-lifecycle contract
- `runtime-readiness.md`
- `agent-console.md`

## Boundary Rule

Cross-surface modules may summarize, inspect, validate, correlate, or route
boundary posture. They do not become an authority merely because they aggregate
multiple domains. Any mutation or decision must identify its source, target,
validation, exception, orchestration, and canonical-write owner.
