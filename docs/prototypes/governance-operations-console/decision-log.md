# Workspace Governance Operations Console Decision Log

## 2026-05-06

- Decision: treat the console as the operator face for the whole governed
  workspace system, not only WGCF.
- Status: design baseline pending.
- Decision: start with the `Today` screen as the first operator surface, with
  `LANES`, control proof, logged-in operator identity, and inactive model
  readiness visible from the first screen.
- Decision: keep the first prototype read-only and synthetic. Runtime approvals,
  model invocation, identity, and durable approval storage remain out of scope
  until the design baseline is accepted.
